# School Portal

School portal starter app for admin and student login with Class 10 study resources.

## Features
- Admin login
- Student login
- Class 10 panel with 6 subjects
- Hindi/English medium support
- Notes management
- Video management
- Schedule management
- Live class management
- Fee tracking
- Demo data stored in browser localStorage

## Run locally
```bash
npm install
npm run dev
```

Then open: http://localhost:3000

## Pages
- `/login` - login page
- `/admin/class10` - admin control for Class 10
- `/student/class10` - student view for Class 10

## Notes
This is a working starter for demo and iteration. For production, replace localStorage with a database and secure auth provider.
